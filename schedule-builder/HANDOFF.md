## A. まず確認してほしいこと（15分）

### A-0. 購入フローを試す（決済なし）

```bash
cd schedule-builder
export PLANNER_SECRET="$(python3 -c 'import secrets;print(secrets.token_hex(32))')"
PYTHONPATH=src python3 -m planner serve
```

http://127.0.0.1:5000/ を開き、「テスト購入する（無料）」から最後まで進んでください。
購入者が見る画面そのものです。文言・入力項目の過不足を見てもらえると助かります。


### A-1. 実物をGoodNotesで開く ★最優先

生成したPDFを iPad の GoodNotes に取り込み、次を確認してください。

- [ ] カレンダーの日付をタップ → その週のページに飛ぶか
- [ ] 週ページの「年間カレンダー」「年間行事予定」「◀ ▶」ボタンが効くか
- [ ] サイドバーのしおりから週ページに飛べるか
- [ ] ペンで書き込んだとき、日付・授業名が邪魔にならないか（左上寄せにしてあります）
- [ ] 授業の色分けが見やすいか（薄すぎ／濃すぎ）
- [ ] 夏休み等の週ページの見え方（グレー＋休業名）が意図に合っているか
- [ ] 書き込んだ**後**もリンクが生きているか

**ここだけは私に確認できません。** リンクが飛ばない場合は、どのページのどのリンクかを
教えてもらえれば直せます（実体化処理は入れてあるので、飛ばない可能性は低いはずです）。

### A-2. レイアウトが現行の紙面と合っているか

現行Excelの紙面と見比べて、足りない欄・不要な欄を教えてください。
`src/planner/static/planner.css` と `templates/planner.html.j2` の修正だけで済みます。

いま実装している週ページの構成:
- 左: 時間割グリッド（朝／1〜4／昼／5・6／業後 × 月〜金）
- 右: 日別メモ欄（月〜金＋土日）、指導計画欄（5行）、フリーメモ欄

## B. 決めてほしいこと（設計に影響する）

### B-1. 販売と決済の方法 ★これが決まらないと先に進めない

| 案 | 手間 | 向いている場面 |
|---|---|---|
| **手動運用**（今すぐ可能） | 注文ごとにコマンド1回 | 月10件くらいまで |
| BOOTH / note で販売＋手動生成 | 決済は任せられる | 月10〜30件 |
| 自前サイト＋Stripe で全自動 | 実装2〜3週間 | 月30件以上 |

**推奨は「まず手動運用で売ってみる」**です。仕組みはもう動くので、
需要が見えてから全自動化にお金と時間をかけるほうが安全です。

決めてほしいこと:
- [ ] どこで売るか
- [ ] 価格
- [ ] 1注文で何をどこまで許すか（年度1つ？ 作り直し何回まで？）

### B-2. 商品の単位

### B-3. サポート範囲の線引き ★トラブル防止に重要

## C. 用意してほしいもの

### C-1. PDFリンくんのソースコード（あれば）

Netlify にデプロイしている元のリポジトリを教えてください。
**伊神モードの正確な仕様**がわかれば、旧Excel由来PDFのリンカー（`linker.py`）を
完全に一致させられます。
※ 新方式では使わないので、無くても販売には支障ありません。

### C-2. 実際の学校の行事予定表（サンプル数種）

勤務校のもの以外に2〜3校分あると、`import-events` の対応形式を広げられます。
**個人情報・学校名は消したもの**で構いません。形式さえわかれば十分です。

### C-3. 販売用の署名鍵の保管

```bash
python3 -c 'import secrets;print(secrets.token_hex(32))'
```

で作った文字列を `PLANNER_SECRET` として保存してください。
**これが漏れるとダウンロードURLを偽造されます。** パスワード管理ソフトに入れてください。
また、**変更するとそれまでに発行したURLが全部無効になります**（再発行は可能）。

## いま動かせる最短の手順

```bash
cd schedule-builder
pip install -r requirements.txt

# 1. ひな形を作って、時間割と行事を書き込む
PYTHONPATH=src python3 -m planner sample --out 私の入力.json

# 2. 中身を確認
PYTHONPATH=src python3 -m planner check -i 私の入力.json

# 3. PDFを作る（4秒）
PYTHONPATH=src python3 -m planner build -i 私の入力.json -o 完成.pdf
```

まずこれを自分の時間割で試して、GoodNotes で開いてみてください。
そこで出てきた不満点が、次に直すべきものです。
