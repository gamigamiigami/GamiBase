# 入力仕様（input.json）

購入者から受け取るデータの正本。**この JSON だけで最終PDFが一意に決まる**ように設計している。
逆に言えば、この JSON さえ保存しておけば、いつでも同じPDFを再生成できる。

## 最小の例

```json
{
  "schoolYear": 2025,
  "timetable": { "grid": { "月": { "1": "２年５組" } } },
  "events": [{ "date": "2025-04-08", "title": "入学式" }]
}
```

## 全項目

| キー | 型 | 必須 | 既定値 | 説明 |
|---|---|---|---|---|
| `schoolYear` | 数値 | ✅ | — | 年度（西暦4桁）。`2025` = 令和7年度 = 2025年4月〜2026年3月 |
| `title` | 文字列 | | 自動 | 表示タイトル。省略時は「令和7年度（2025年度）スケジュール帳」 |
| `owner.name` | 文字列 | | `""` | 使用者名。1ページ目に表示 |
| `owner.school` | 文字列 | | `""` | 学校名。1ページ目に表示 |
| `timetable.grid` | オブジェクト | | `{}` | `{曜日: {時限: 授業名}}`。曜日は `月火水木金`、時限は `"1"`〜`"6"` |
| `timetable.periods` | 配列 | | `["朝","1","2","3","4","昼","5","6","業後"]` | 週ページの行構成。行の増減・改名ができる |
| `events` | 配列 | | `[]` | 年間行事。`{date, title, note?}` |
| `events[].date` | 文字列 | ✅ | — | `YYYY-MM-DD`。年度の範囲外はエラー |
| `events[].title` | 文字列 | ✅ | — | 行事名 |
| `events[].note` | 文字列 | | `""` | 補足（「午前日課」など）。`行事名（補足）` と表示される |
| `freePages` | 数値 | | `30` | 巻末の自由ページ数（0〜200） |
| `extraWeeks` | 数値 | | `1` | 年度末の翌週を何週分よぶんに付けるか（0〜8）。現行Excelに合わせて既定1 |
| `license.orderId` | 文字列 | | `""` | 注文ID。フッタの透かしとPDFメタデータに入る |
| `license.issuedTo` | 文字列 | | `""` | 購入者名。フッタの透かしに入る |
| `license.watermark` | 真偽 | | `true` | `false` で透かし非表示（メタデータには残る） |

> `license` は `order-build` コマンドを使う場合、注文台帳の値で**上書きされる**。
> 購入者が自分で書き換えても透かしは消せない。

## ページ構成（自動計算）

```
1ページ目      年間カレンダー
2ページ目      年間行事予定
3ページ目〜    週ページ（第1週 … 第N週）
その後         自由ページ（freePages 枚）
```

- 週は**月曜始まり**。第1週は「4月1日を含む週」。
- 最終週は「翌年3月31日を含む週」＋ `extraWeeks`。
- 年度により週数は 52〜54 週（4/1の曜日とうるう年で変わる）。
  令和7年度は 54週 → 総ページ 86（現行Excelと一致）。

## 祝日について

祝日は**入力しない**。年度から自動計算される（`holidays.py`）。

- 固定日・ハッピーマンデー・春分/秋分・振替休日・国民の休日に対応
- 2020/2021 の五輪特措法による移動にも対応
- 1980〜2099 年で有効

法改正で祝日が変わった場合は `holidays.py` の修正が必要（→ HANDOFF.md）。

## バリデーション

`python3 -m planner check -i input.json` で検証できる。
エラーメッセージは**そのまま購入者に見せられる日本語**で書いてある。

主なエラー:

| 状況 | メッセージ |
|---|---|
| 年度未指定 | `schoolYear（年度）が指定されていません。…` |
| 行事の日付が年度外 | `events[3]: 日付 2027-04-08 は年度の範囲（2025-04-01 〜 2026-03-31）外です。…` |
| 曜日が不正 | `timetable.grid: 曜日 '土' は使えません。月・火・水・木・金 のいずれかにしてください` |
| 日付の書式違い | `events[1]: 日付 '4月8日' を解釈できません。'YYYY-MM-DD' 形式で指定してください` |

> 行事予定を `4月8日` のようなゆるい書式で受け取りたい場合は、
> `import-events` コマンドを通してから `events` に入れる（正規化される）。
