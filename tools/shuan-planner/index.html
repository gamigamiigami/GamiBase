先生のスケジュール帳

時間割と行事予定を入力すると、リンク付きPDFを自動で作ります。GoodNotes に取り込んで、そのまま手書きで使えます。

本番ではここが決済ボタンになります。決済後、同じ入力フォームに進みます。

スケジュール帳の内容を入力

注文番号 ORD-D7EBCC4981EA ／ 令和8年度版
作成できるのは1回だけです。内容をよく確認してから作成してください。

1. 基本情報

入力が必要なのは自由ページ数だけです。ほかは空欄のままでも作成できます。

2. 時間割（授業名と色）任意

空欄の枠は空きコマになります。

月火水木金

3. 長期休業任意

よくある期間を入れてあります。学校に合わせて直してください。祝日・振替休日は年度から自動計算されるので入力不要です。

4. 年間行事予定任意

学校の行事予定表（CSV / Excel）をアップロードするか、貼り付けてください。 日付は 4/8・4月8日・2026-04-08 のどれでも読めます。

生成はおよそ4秒で終わります。

手元で動かす

PDF生成まで含めた本物が、この3画面で動きます。

cd schedule-builder
pip install -r requirements.txt
export PLANNER_SECRET="$(python3 -c \
  'import secrets;print(secrets.token_hex(32))')"
PYTHONPATH=src python3 -m planner serve

→ http://127.0.0.1:5000/

インターネットに公開する

Render に render.yaml を読み込ませると、この通りに構築されます。

Render → New → Blueprint
  → gamigamiigami/GamiBase を選ぶ
  → Apply（5〜10分）

手順の詳細と他の方法は schedule-builder/DEPLOY.md。

決済は /checkout の1か所だけに閉じ込めてあります。本番化はそこを差し替えるだけで、 生成・ライセンス・ダウンロードの仕組みは変更不要です。
