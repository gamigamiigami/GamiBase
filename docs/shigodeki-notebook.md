# シゴデキ先生：ノートの使い方

- 「週案ノート」は、月〜金の時間割、朝・昼・業後、右側の日別行事、指導計画、メモを1枚に表示します。「土日の授業」で7日表示にも切り替えられます。
- 「年間カレンダー」は4列×3段、「年間行事予定」は12か月の一覧です。日付をタップして入力した行事は、週案の行事欄にも反映されます。
- コマをタップして授業・授業メモを保存すると、赤字で「変更」と表示します。「基本時間割に戻す」で変更を解除できます。授業をなくす場合は「空き時間」を選びます。
- 「直線」は始点から終点へドラッグします。「ペン」でも描いたまま約0.6秒止めると直線になります。離す前に終点の位置を調整できます。
- 色の丸をタップするとお気に入り色を選べます。色ピッカーで色を選び「色を登録」を押すと、選択中の丸の色を置き換えて保存します。
- 横画面では表示領域の幅と高さを使ってノート全体を表示します。＋／−で50〜300%に拡大・縮小でき、「全体表示」で戻せます。iPadなどのタッチ画面では2本指でピンチ、拡大中は1本指で表示位置を動かせます。指で描く場合は「指では書かない」を外してください。
- 年間カレンダーの日付を押すと「内容を入力」「週案を開く」が表示されます。内容を編集してから週案を開く場合も、入力を保存して移動します。
- 「印刷・PDF」で表示中のノートをA4横向きに印刷できます。PDF保存はブラウザの印刷画面で選びます。

行事・記入欄・お気に入り色・年間ページの手書きは、既存のノートと同じアカウント専用の保存領域に保存します。既存のバックアップも読み込めます。保存済みになってからページを閉じてください。
