# シゴデキ先生 週案ノート（PWA）

Excel/PDFを経由せず、ブラウザ上で時間割・時数・手書きを管理するアプリ版です。購入案内は `tools/shigodeki-sensei/index.html`、従来のPDF生成は `tools/shigodeki-sensei/pdf.html` で利用できます。PDF作成デモでは決済・コード発行を行いません。iPadのSafariから「共有 → ホーム画面に追加」すると独立したウィンドウで起動できます。App Storeへの登録・有料開発者アカウントは不要です。

## 起動と動作確認

Node.js 24以上を使い、リポジトリのルートで実行します。外部npmパッケージはなく、`npm install`は不要です。

```bash
npm start
```

標準では127.0.0.1の3000番でアプリ専用サーバーが動きます。ページのパスは `/tools/shigodeki-sensei/app/` です。ルートへのアクセスもこのページに移動します。

データは標準で**リポジトリの隣の `.shigodeki-data/app.sqlite`** に保存されます。このクラウド環境では `/workspace/.shigodeki-data/app.sqlite` です。既存の静的サイトの公開ディレクトリ内に購入者のデータを置かないでください。

```bash
npm test
# ブラウザの統合確認（Python Playwright と Chromium が必要）
python3 tests/browser_smoke.py
```

ブラウザ確認では独立した一時DBと一時アカウントを使用し、終了時に削除します。スクリーンショットはGit管理外の `test-results/` に出力します。Chromiumの場所を変える場合は `CHROMIUM_PATH` を指定します。

## 購入者への利用コード発行

販売者が購入を確認した後、**本番サーバーで**実行します。`SHIGODEKI_DATA_DIR` を変更している場合はサーバーと同じ値で実行してください。

```bash
npm run license -- issue buyer@example.com
```

出力されたコードを、その購入者本人へ安全な方法で渡します。コードをGit、公開ページ、共通の案内文などに保存しないでください。

1. 購入者がアプリを開き「はじめての方・利用コードをお持ちの方」を選びます。
2. コード発行先と同じメールアドレス、12文字以上のパスワード、利用コードで登録します。
3. 自分の担当授業・基本時間割・休業期間を設定します。
4. 以後はメールアドレスとパスワードでログインします。

コードは30日間有効・一回限り・メールアドレス固定です。登録済みの購入者に新しいコードを発行すると、そのコードでパスワードを再設定できます。販売者が本人確認してから再発行してください。自動決済・自動メール送信・メールアドレス変更は、この初版には含めていません。

```bash
# 返金・不正利用等で利用停止（未使用コードとセッションも無効化）
npm run license -- revoke buyer@example.com
# 利用を再開
npm run license -- restore buyer@example.com
```

## 時数と時間割の仕様

- 1コマを1時数として、**クラスと教科の組ごと**に集計します。初版の時間割は月〜日・1〜6限です。
- 「この週の予定」は予定と実施済みを含め、休講を除外します。
- 「累計・実施済み」は年度初めから、表示週の末日と今日のうち早い方までに**実施済みにした授業**を数えます。過去の予定を自動で実施済みにしません。
- 補助表示の「この週までの予定累計」は表示週末までの予定を含む時数です。
- 個別のコマを開いて授業・状態・授業メモを変更できます。日付の「✓ 実施」はその日の予定授業をまとめて実施済みにします。
- 振替先が空きなら移動、授業があれば交換します。実施済みの授業は誤変更防止のため直接振替できません。先に状態を変更してください。
- 基本時間割は適用開始日ごとに保持します。新しい時間割は開始日以降に適用されます。個別に変更したコマは維持します。
- 祝日・振替休日・国民の休日は自動で授業なしとし、任意の休業期間も登録できます。休日に個別に授業を入れることもできます。祝日は2025〜2099年の現行ルールによる計算で、臨時の法改正は設定・コード側の更新が必要です。
- 初版は1アカウントにつき1年度のノートです。履歴を守るため、使用開始後は設定画面で年度を変えられません。複数年度の同時管理や既存Excel/PDFからの自動移行は未対応です。

## 手書きと保存

- 週案全体と下部のメモ欄に書けます。ペン、マーカー、色、太さ、筆圧、ひと筆単位の消しゴム、取り消し・やり直しに対応します。
- 標準はペンとマウスのみで描画。「指では書かない」がオンのときは指で移動できます。ペン入力中の指入力は描画に使用しません。
- 手書きは週・位置に紐づきます。振替時に授業と一緒には移動しません。週を切り替えても同じ位置に戻ります。
- 自動保存はサーバーと端末のIndexedDBを使用します。サーバー保存が完了するまで「保存済み」と表示しません。
- 開いた後に接続が切れても、編集内容は端末に一時保存し、接続後に同期します。**起動・再読込・ログイン時はオンライン認証が必要**です。完全なオフラインアプリではありません。
- 同じアカウントの別タブが先に保存した場合は、上書きを止めて復旧を案内します。端末の変更をバックアップし、サーバー側のノートを開きます。
- バックアップはJSONで書き出し・復元できます。復元前には元のノートを自動で書き出します。復元はノート全体の置き換えです。
- データ容量は1ノート8MiB、手書き20万ポイントなどの上限があります。上限時は保存エラーを表示します。サーバー保存成功を確認してからページを閉じてください。
- Safari/Apple Pencil実機での筆圧の感触、パームリジェクション、ホーム画面インストールは実機確認が必要です。GoodNotesと同等の描画エンジンを提供するものではありません。

## 購入者制限の範囲

ノート取得・保存のすべてでサーバー側の権限を確認します。パスワードはscryptでハッシュ化し、利用コード・セッションもハッシュだけをDBに保存します。セッションCookieはHttpOnly・SameSite=Strict、本番HTTPSではSecureです。APIは同一オリジンのみ受け付け、ログイン試行回数を制限します。

同時に有効なのは1アカウント1セッションです。別端末でログインすると旧セッションを無効化し、旧画面は保存・復帰時または定期確認でロックされます。セッションは7日間有効です。ノートや認証APIはService Workerのキャッシュに入れません。

URL共有だけで他人が使うことはできません。ただし、購入者がパスワードそのものを他人に渡す行為、取得済みのデータやバックアップのコピーを技術だけで完全に防ぐことはできません。オフラインの開いた画面には既に取得したノートが残ります。利用停止は次のサーバー通信時に反映します。

## 本番公開

**GitHub Pagesだけでは認証サーバーを実行できません。** 既存のPDFサイトはPagesのまま維持し、アプリはNode.js 24が動く別のサーバーで公開します。この変更は本番へのデプロイを行いません。

必要なものは次の3点です。

1. Node.js 24の常駐プロセスを動かせるホスティング。
2. DBを保持する永続ディスク（再デプロイで消える一時ディスクは不可）。
3. 独自URLとHTTPS。アプリ画面とAPIを**同じオリジン**で配信します。

環境変数の例（ドメインは実際のものに置き換えます）:

```bash
APP_ORIGIN=https://planner.example.com
HOST=127.0.0.1
PORT=3000
SHIGODEKI_DATA_DIR=/var/lib/shigodeki
```

HTTPSのリバースプロキシからNodeサーバーへ転送し、`APP_ORIGIN` を外部URLと完全一致させます。プロキシが別コンテナの場合は、信頼された内部ネットワークで `HOST=0.0.0.0` を使用できます。Nodeを直接HTTPでインターネットへ公開しないでください。静的ファイルとAPIのルーティングはNodeサーバーが行います。

`SHIGODEKI_DATA_DIR` はアプリ実行ユーザーだけが読み書きできるようにし、DBを定期バックアップします。SQLiteはWALモードのため、稼働中の `app.sqlite` だけをコピーせず、SQLiteのオンラインバックアップ機能を使うか、停止後に一貫したバックアップを取得してください。初版は単一プロセス・単一永続ディスクを前提としています。

初回公開では、テスト用の購入者を本番サーバーで発行して登録・保存・再ログイン・コード再利用拒否を確認し、iPadでホーム画面追加と手書きを確認してください。その後、既存サイトから実際のアプリURLへ案内します。公開先未設定のまま、Pages上のアプリフォルダを購入者へ案内しないでください。

アプリの変更時は `sw.js` のキャッシュ名を更新します。開いているノートの未保存内容を守るため、新版は既存のウィンドウを閉じてから有効になります。

## ファイル構成

| 場所                          | 内容                                                |
| ----------------------------- | --------------------------------------------------- |
| `tools/shigodeki-sensei/app/` | PWA、週案画面、集計モデル、手書き、ローカル一時保存 |
| `server/index.mjs`            | 認証API、ノート保存、専用静的配信                   |
| `server/store.mjs`            | SQLite、パスワード・利用コード                      |
| `server/admin.mjs`            | 販売者用のコード発行・利用停止                      |
| `tests/*.test.mjs`            | 時数モデルと購入者権限のテスト                      |
| `tests/browser_smoke.py`      | 実ブラウザでの利用フロー確認                        |
